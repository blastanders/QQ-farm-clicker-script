# How to use 如何使用
打开农场的微信小程序，然后运行
```python3 click_hand_v2.py```


只在苹果terminal上跑过。需要给terminal录屏和鼠标的权限。
缺什么lib装什么lib，关于lib的问题问ai就好。不要问我。。。Use your big brain.

如果发现鼠标不准或者明明有按钮但是不点的话，运行 ```python3 click_hand_v2.py --tune-offset-y``` 输入1-10来调整截图的 y 高度，可以输入小数。输入完数字按回车会得到一张1像素的预览，调整数字直到看到绿棕相间的一条线。
注意，按钮的高度在你自己的农场和别人的农场不一样，找个带按钮的好友做测试。

找到合适的高度以后去代码里改ANCHOR_OFFSET_Y， 把你输入的数加到ANCHOR_OFFSET_Y就好了。
